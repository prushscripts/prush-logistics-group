# Truck Branding Refinement Prompt for Bing Image AI

## Main Prompt

```
Professional delivery fleet photo, three white commercial cargo vans (Nissan NV Cargo and Fiat Ducato models) parked diagonally side-by-side against a light grey wall on dark asphalt, professional logistics company branding, even lighting, high resolution. 

BRANDING DETAILS:
- Large "PRUSH" text in bold orange sans-serif font on each van's side panel
- The letter 'H' in "PRUSH" has a right-pointing arrow seamlessly integrated and blended into the right vertical stroke of the H, creating one unified element (arrow should flow naturally from the H, not look separate or awkward)
- Below "PRUSH", smaller "LOGISTICS GROUP" text in orange, proportionally sized at approximately 40-45% of the PRUSH text height, properly spaced and aligned
- On the rightmost van: full slogan "We put the rush in Prush" in italicized orange font, positioned below "LOGISTICS GROUP"
- On the middle and leftmost vans: partial slogan visible showing "We put the rush..." (beginning of text visible on the side panel, consistent with rightmost van)
- Orange horizontal curved stripe running along lower side of each van from front wheel arch toward rear
- All branding elements consistent across all three vans for professional uniformity
- Text sizing and spacing creates balanced, professional logo hierarchy

STYLING:
- Clean, modern commercial vehicle design
- Vibrant orange (#EA580C) branding color
- Professional fleet appearance
- Consistent branding application across all vehicles
```

## Specific Refinement Points (Use These in Follow-up)

1. **Arrow Integration:**
   - "Make the arrow on the H blend seamlessly into the right vertical stroke, creating one unified letterform"
   - "The arrow should appear to flow naturally from the H, not look like a separate element attached"

2. **Text Sizing:**
   - "Reduce LOGISTICS GROUP font size to 40-45% of PRUSH text height"
   - "Improve spacing between PRUSH and LOGISTICS GROUP for better visual hierarchy"
   - "Ensure LOGISTICS GROUP is proportionally balanced relative to PRUSH"

3. **Slogan Visibility:**
   - "Show full slogan 'We put the rush in Prush' on rightmost van"
   - "Show partial slogan 'We put the rush...' on middle and leftmost vans (beginning visible)"
   - "Ensure slogan positioning is consistent across all three vans"

4. **Consistency:**
   - "All branding elements should be identical in size, placement, and styling across all three vehicles"
   - "Maintain professional fleet uniformity"

## Tips for Bing Image AI

- Upload your current image first
- Use "Edit" or "Modify" mode
- Be specific about what needs to change
- You can do multiple iterations:
  1. First fix the arrow integration
  2. Then adjust text sizing
  3. Finally add slogan visibility

## Expected Result

- Seamlessly integrated H-arrow element
- Properly proportioned logo text hierarchy
- Consistent slogan visibility across all three vans
- Professional, uniform fleet branding
