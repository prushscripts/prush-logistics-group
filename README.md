# Prush Logistics Group LLC — Website

Professional marketing website for **Prush Logistics Group LLC**, a New York–based company providing automotive parts transportation between dealerships and repair facilities.

## Tech stack

- **HTML** — Semantic markup, single-page layout
- **CSS** — Custom styles (`css/styles.css`), premium theme; responsive design
- **JavaScript** — Interactivity, navigation, theme toggle, contact form (`js/script.js`)

## Project structure

```
/
├── index.html          # Main page
├── README.md           # This file
├── css/
│   ├── styles.css      # Primary styles + premium theme
│   └── premium.css     # Premium theme source (optional)
├── js/
│   └── script.js      # Site behavior
└── images/             # Logos, fleet photos, assets
```

## Hosting

- **Vercel** — Site is built and deployed from this repository. Push to the connected branch to trigger a new deployment.
- **Domain:** prushlogistics.com

## Local development

1. Clone the repo and open the project folder.
2. Open `index.html` in a browser, or run a local server:
   ```bash
   # Python
   python -m http.server 8000

   # Node (npx)
   npx http-server
   ```
3. Visit `http://localhost:8000` (or the port shown).
