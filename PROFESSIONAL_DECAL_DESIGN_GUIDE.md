# Professional Truck Decal Design Guide - Photopea

## ⚠️ CRITICAL: Print Requirements

For professional decals, you need:
- **300 DPI minimum** (dots per inch) for print quality
- **Vector or high-resolution raster** files
- **CMYK color mode** (not RGB) for accurate printing
- **Exact measurements** - know your van's side panel dimensions
- **Bleed area** - extra space around edges for cutting

---

## Step 1: Set Up Your Document in Photopea

### 1.1 Create New Document
1. Open **Photopea.com**
2. Go to **File → New**
3. Set dimensions:
   - **Width:** Measure your van's side panel (e.g., if 8 feet = 96 inches)
   - **Height:** Measure height needed (e.g., 24 inches)
   - **Resolution:** **300 PPI** (pixels per inch) - CRITICAL for print
   - **Color Mode:** **CMYK Color** (for accurate printing)
   - **Background:** Transparent (if decal is cut-out) or White

### 1.2 Example Settings:
- **Width:** 96 inches (8 feet)
- **Height:** 24 inches
- **Resolution:** 300 PPI
- **Color Mode:** CMYK
- **Result:** 28,800 x 7,200 pixels (huge file, but necessary!)

---

## Step 2: Design Your Logo Layout

### 2.1 Create Text Layers

**Layer 1: "PRUSH"**
1. Select **Text Tool** (T key)
2. Click on canvas
3. Type: **"PRUSH"**
4. Font: **Bold Sans-Serif** (Arial Black, Helvetica Bold, or similar)
5. Size: Start with **12-14 inches** (adjust based on your van size)
6. Color: **Orange** - Use CMYK values: **C:0 M:65 Y:100 K:0** (or #EA580C converted)
7. Position: Center horizontally, top portion of canvas

**Layer 2: Arrow on H**
1. Create new layer
2. Use **Pen Tool** (P key) or **Shape Tool** (U key)
3. Draw arrow extending from right side of H
4. Make it **seamlessly blend** into the H
5. Color: Same orange as PRUSH
6. Merge with PRUSH text or keep separate (your choice)

**Layer 3: "LOGISTICS GROUP"**
1. Select **Text Tool** (T key)
2. Type: **"LOGISTICS GROUP"**
3. Font: **Regular Sans-Serif** (Arial, Helvetica, or match PRUSH font family)
4. Size: **40-45% of PRUSH height** (if PRUSH is 12", make this 5-5.5")
5. Color: **Grey** - Use CMYK: **C:0 M:0 Y:0 K:60** (60% black)
6. Position: **Directly below PRUSH** with tight spacing (about 0.5-0.75 inches gap)
7. Align: Center with PRUSH

**Layer 4: Tagline "We put the rush in Prush"**
1. Select **Text Tool** (T key)
2. Type: **"We put the rush in Prush"**
3. Font: **Italic, Regular weight** (slightly lighter than LOGISTICS GROUP)
4. Size: **30-35% of PRUSH height** (if PRUSH is 12", make this 3.5-4")
5. Colors:
   - "We put the" - Grey: **C:0 M:0 Y:0 K:50**
   - "rush" - Orange: **C:0 M:65 Y:100 K:0** (italic, bold)
   - "in" - Grey: **C:0 M:0 Y:0 K:50**
   - "Prush" - Grey: **C:0 M:0 Y:0 K:50** (not orange - more subtle)
6. Position: Below LOGISTICS GROUP, about 0.5 inches gap
7. Align: Center with everything above

### 2.2 Orange Stripe (Optional)
1. Create new layer
2. Use **Pen Tool** or **Shape Tool**
3. Draw curved stripe along bottom
4. Color: Same orange as PRUSH
5. Position: Lower portion of design

---

## Step 3: Professional Spacing & Alignment

### 3.1 Spacing Guidelines:
- **PRUSH to LOGISTICS GROUP:** 0.5-0.75 inches (tight, cohesive)
- **LOGISTICS GROUP to Tagline:** 0.5 inches
- **Overall vertical spacing:** Balanced, not too spread out

### 3.2 Alignment:
- Use **Align Tools** (View → Show → Rulers, then use guides)
- Everything should be **centered horizontally**
- Use **snap to guides** for perfect alignment

### 3.3 Typography Hierarchy:
1. **PRUSH** - Largest, boldest, orange (primary)
2. **LOGISTICS GROUP** - Medium, grey (secondary)
3. **Tagline** - Smallest, grey with orange accent (tertiary)

---

## Step 4: Color Accuracy for Print

### 4.1 Convert to CMYK:
1. Go to **Image → Mode → CMYK Color**
2. This ensures accurate color printing

### 4.2 Color Values:
- **Orange:** C:0 M:65 Y:100 K:0 (or get exact match from your printer)
- **Grey (LOGISTICS GROUP):** C:0 M:0 Y:0 K:60
- **Grey (Tagline):** C:0 M:0 Y:0 K:50

### 4.3 Get Color Match from Printer:
- **Ask your decal printer** for their orange color code
- They may use **Pantone colors** (e.g., Pantone 1585 C)
- Match exactly to avoid color discrepancies

---

## Step 5: Add Bleed Area

### 5.1 What is Bleed?
- Extra space around your design for cutting
- Prevents white edges if cut is slightly off

### 5.2 Add Bleed:
1. Go to **Image → Canvas Size**
2. Add **0.125 inches (1/8 inch)** to all sides
3. This gives you safe cutting area

---

## Step 6: Export for Print

### 6.1 File Formats:
- **PDF** (best for print) - Vector or high-res raster
- **EPS** (vector format, best quality)
- **PNG** (high-res, 300 DPI, if printer accepts)
- **AI** (Adobe Illustrator - if you have it)

### 6.2 Export Settings:

**For PDF:**
1. **File → Export As → PDF**
2. Quality: **Maximum**
3. Compression: **None** (for best quality)
4. Color Profile: **CMYK**

**For PNG (if needed):**
1. **File → Export As → PNG**
2. Make sure resolution is still **300 PPI**
3. Use **24-bit color**

### 6.3 Final Checklist:
- ✅ 300 DPI resolution
- ✅ CMYK color mode
- ✅ Bleed area added
- ✅ All text is readable and properly sized
- ✅ Colors match your brand
- ✅ File saved in print-ready format

---

## Step 7: Professional Refinements

### 7.1 Typography Tweaks:
- **Letter spacing (tracking):** Slightly tighten PRUSH letters (maybe -10 to -20)
- **Line height:** Ensure proper spacing between lines
- **Font weight:** PRUSH = Bold, LOGISTICS GROUP = Regular, Tagline = Light/Regular

### 7.2 Visual Balance:
- Everything should feel **centered and balanced**
- **White space** is important - don't crowd elements
- **Visual weight** should flow: PRUSH (heaviest) → LOGISTICS GROUP → Tagline (lightest)

### 7.3 Final Polish:
- **Remove any unnecessary layers**
- **Flatten if needed** (but keep editable version too!)
- **Check for pixelation** - zoom to 100% to verify
- **Test print** a small version first if possible

---

## Step 8: Create Multiple Versions

### 8.1 Different Sizes:
- **Full side panel** version (what you're making)
- **Smaller version** for doors or rear panels
- **Horizontal version** if needed

### 8.2 Keep Editable Files:
- Save **.psd** (Photopea format) for future edits
- Save **print-ready PDF** for printer
- Keep both!

---

## Step 9: Work with Your Decal Printer

### 9.1 Questions to Ask:
- What file format do you prefer? (PDF, EPS, AI?)
- What resolution do you need? (usually 300 DPI)
- Do you need CMYK or RGB? (usually CMYK)
- What color system do you use? (Pantone, CMYK values?)
- Do you need bleed area? (usually yes, 1/8 inch)
- What are your maximum dimensions?

### 9.2 Provide to Printer:
- High-resolution file (300 DPI minimum)
- Exact dimensions of your van's side panel
- Color specifications (CMYK or Pantone codes)
- Any special requirements (cut-out, full coverage, etc.)

## Pro Tips

1. **Start with measurements** - Know your van's exact dimensions
2. **Test at actual size** - Print a paper mockup to see how it looks
3. **Get color samples** - Ask printer for color swatches before final print
4. **Keep it simple** - Less is more for vehicle graphics
5. **Consider visibility** - Make sure it's readable from distance
6. **Durability** - Ask about UV-resistant inks for outdoor use
7. **Installation** - Some printers offer installation services

---

## Common Mistakes to Avoid

- ❌ Using RGB instead of CMYK (colors will be off)
- ❌ Low resolution (will look pixelated when printed large)
- ❌ Forgetting bleed area (white edges when cut)
- ❌ Not getting exact color match from printer
- ❌ Text too small (won't be readable from distance)
- ❌ Too much spacing (looks disconnected)
- ❌ Not testing at actual size first
