## 🎨 Photopea Steps (If AI Can't Fix It)

### Part 1: Fix Website & Phone Number

#### Step 1: Remove Old Text
1. **Select Lasso Tool** (L key)
2. **Draw around website and phone number** on passenger door
3. **Select → Modify → Expand → 2 pixels**
4. **Edit → Fill → Content-Aware → OK**
5. **Press Ctrl+D** to deselect

**Alternative if Content-Aware doesn't work:**
- **Clone Stamp Tool** (S key)
- **Hold Alt**, click on clean white area of door
- **Paint over** the text to remove it

---

#### Step 2: Create New Website Text
1. **Select Text Tool** (T key)
2. **Click on passenger door** where website should go
3. **Type:** "PRUSHLOGISTICS.COM" (or correct spelling)
4. **In toolbar, set:**
   - **Font:** Sans-serif, regular weight
   - **Size:** **30-40% smaller** than current (if current is 60px, make it 36-42px)
   - **Color:** Dark grey (#666666) or match existing color
   - **Style:** Regular (not bold)

5. **Position:**
   - On passenger door
   - Professional placement
   - Use **Move Tool** (V key) to position

---

#### Step 3: Create New Phone Number Text
1. **Select Text Tool** (T key)
2. **Click below website** (or where phone should go)
3. **Type:** "1-845-444-0804" (or correct number)
4. **In toolbar, set:**
   - **Font:** Same as website (sans-serif, regular)
   - **Size:** **Same size as website** (30-40% smaller than original)
   - **Color:** Dark grey (#666666) or match existing
   - **Style:** Regular

5. **Position:**
   - Below website
   - Aligned with website
   - Use **Move Tool** (V key) to position

---

### Part 2: Fix PLG Numbers

#### Step 4: Remove Old PLG Text
1. **Select Lasso Tool** (L key)
2. **Draw around "PLG 1"** (on first van)
3. **Select → Modify → Expand → 2 pixels**
4. **Edit → Fill → Content-Aware → OK**
5. **Repeat for PLG 2 and PLG 3**

**Or use Clone Stamp:**
- **Clone Stamp Tool** (S key)
- **Hold Alt**, click on clean white area
- **Paint over** each PLG number

---

#### Step 5: Create New Smaller PLG Numbers
1. **Select Text Tool** (T key)
2. **Click where PLG 1 should be** (front door area)
3. **Type:** "PLG 1"
4. **In toolbar, set:**
   - **Font:** Sans-serif, regular weight
   - **Size:** **30-40% smaller** than current (if current is 50px, make it 30-35px)
   - **Color:** Dark grey (#666666) or match existing
   - **Style:** Regular (not bold)

5. **Position:**
   - On front door area
   - Subtle but visible
   - Use **Move Tool** (V key) to position

6. **Duplicate for other vans:**
   - **Right-click PLG 1 layer → Duplicate Layer**
   - **Edit text** to "PLG 2"
   - **Move to second van**
   - **Repeat for PLG 3**

## 🎨 Pro Tips

### Matching Existing Text:
1. **Use Eyedropper Tool** (I key)

3. **Apply to new text**

### Getting Right Size:
1. **Select old text** (if still visible)
2. **Check font size** in toolbar
3. **Calculate 30-40% smaller**
4. **Apply to new text**

### Positioning:
1. **Use guides** (View → Show → Rulers)
2. **Align with other elements**
3. **Keep consistent spacing**
