# Photopea Canvas Settings for Truck Branding Image

## Recommended Settings

### For Print Reference / Decal Design (Best Quality)

**Dimensions:**
- **Width:** 4000-6000 pixels
- **Height:** 2500-3500 pixels
- **DPI:** 300 (print quality)

**Why:**
- High enough resolution for professional printing
- Decal manufacturers can see details clearly
- Can be scaled down for web/screen use later
- Standard print resolution (300 DPI)

**File Size:** ~20-50 MB (depending on content)

---

### For Screen Reference / Web Use (Balanced)

**Dimensions:**
- **Width:** 2000-3000 pixels
- **Height:** 1200-1800 pixels
- **DPI:** 150-200 (good screen quality)

**Why:**
- Good quality for viewing on screen
- Smaller file size (faster to work with)
- Can still be printed at smaller sizes
- Easier to work with in Photopea

**File Size:** ~5-15 MB

---

### For Quick Editing / Testing (Lightweight)

**Dimensions:**
- **Width:** 1500-2000 pixels
- **Height:** 900-1200 pixels
- **DPI:** 72-150 (screen resolution)

**Why:**
- Fast to work with
- Good for testing designs
- Smaller file size
- Fine for screen viewing

**File Size:** ~2-5 MB

---

## How to Set in Photopea

### If Starting New Image:

1. **File → New**
2. **Set dimensions:**
   - **Width:** 4000 pixels (or your choice)
   - **Height:** 2500 pixels (or your choice)
   - **Resolution:** 300 pixels/inch (DPI)
   - **Color Mode:** RGB Color
   - **Background:** White
3. Click **OK**

### If Opening Existing Image:

1. **Image → Image Size**
2. **Check current size** (note current dimensions)
3. **To resize:**
   - Uncheck **Resample** if you want to change DPI only
   - Or check **Resample** to change pixel dimensions
   - Enter new **Width** and **Height**
   - Set **Resolution** to 300 (for print) or 150 (for screen)
4. Click **OK**

## Aspect Ratio

**For truck side view images:**
- **Recommended:** 5:3 or 16:9 ratio
- **Example:** 5000px × 3000px (5:3)
- **Example:** 4800px × 2700px (16:9)

**Why:**
- Matches typical truck side panel proportions
- Good for showing full branding
- Works well for both print and screen

---

## Color Mode

**Use RGB Color:**
- Photopea default
- Works for both screen and print
- Decal printers can convert to CMYK if needed
- Better color range for editing

**Don't use CMYK unless:**
- Printer specifically requests it
- You're doing final print prep (usually not needed for reference images)

## File Size Tips

**If file is too large:**
- Reduce to 3000px × 1800px (still high quality)
- Use 200 DPI instead of 300
- Save as JPG instead of PNG (when exporting)

**If file is too small:**
- Increase to 6000px × 3600px
- Use 300 DPI
- Keep as PNG for best quality
