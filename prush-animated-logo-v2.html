How to add this to your site

1. Paste the CSS block (everything between the PRUSH LOGISTICS — ANIMATED LOGO COMPONENT comments) into your styles.css

2. Replace your current navbar logo HTML with the .prush-logo-wrap block above — swap the base64 img src for your actual file path: src="/assets/img/transparentPLGLogo.png"

3. For your footer, use the same block but add class="prush-logo-wrap footer-variant"

What animates: Letters slide up on load · Icon breathes gently every 3.5s · Orange halo pulses behind icon · The H glows orange every loop · All CSS-only, zero JavaScript

Cursor prompt for your dev: "Replace the existing logo in the navbar and footer with the .prush-logo-wrap component from the attached HTML file. Copy the CSS into styles.css and the HTML block into the navbar and footer sections of index.html. Use the file path /assets/img/transparentPLGLogo.png for the img src. No JavaScript needed."
