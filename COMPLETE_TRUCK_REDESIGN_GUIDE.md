## 📋 STEP-BY-STEP REDESIGN PROCESS

### **Phase 1: Setup & Preparation**

#### Step 1: Open Your Image in Photopea
1. Go to **https://www.photopea.com**
2. **File → Open** (or drag image into browser)
3. Open **Image 2** (the one with curved stripe and slogan)
4. This will be your **base image** to work from

#### Step 2: Create Backup Layer
1. **Right-click** on background layer in Layers panel
2. **Duplicate Layer**
3. Name it **"Original Backup"**
4. **Hide it** (click eye icon) - keep it safe!

#### Step 3: Create Working Layers
Create separate layers for each element (easier to edit):
1. **Layer → New → Layer** (or click + icon)
2. Name layers:
   - **"PRUSH Logo"**
   - **"LOGISTICS GROUP Text"**
   - **"Arrow Fix"**
   - **"Curved Stripe"**
   - **"Slogan"**

---

### **Phase 2: Fix the Arrow (Image 1 Style)**

#### Step 4: Remove Old Arrow from Image 2
1. **Select Healing Brush Tool** (J key)
2. **Hold Alt**, click on **clean white van area** near the H
3. **Paint over the old arrow** - this removes it cleanly
4. Make sure arrow is completely gone

#### Step 5: Create New Blended Arrow (Image 1 Style)
**Method A: Using Pen Tool (Most Precise)**

1. **Select Pen Tool** (P key)
2. **Create new layer** named "Arrow Fix"
3. **Zoom in** on the H (Ctrl + Plus)
4. **Draw arrow path:**
   - Click on **right vertical stroke of H** (where it should start)
   - Click to create **horizontal line** extending right
   - Click to create **arrow point** (triangle shape)
   - **Right-click path → Make Selection**
   - **Feather:** 1-2 pixels
   - Click **OK**

5. **Fill with orange:**
   - **Edit → Fill** (Shift+F5)
   - Choose **Foreground Color**
   - Set color to **#EA580C** (burnt orange)
   - Click **OK**

6. **Blend arrow into H:**
   - **Select Eraser Tool** (E key)
   - **Soft brush** (0-20% hardness)
   - **Erase edges** where arrow meets H
   - Make it look **seamless and blended**

**Method B: Using Brush Tool (Easier)**

1. **Create new layer** "Arrow Fix"
2. **Select Brush Tool** (B key)
3. **Set color:** #EA580C (orange)
4. **Brush size:** Match H stroke width
5. **Hardness:** 0% (soft edges)
6. **Draw arrow:**
   - Start from **right side of H**
   - Draw **horizontal line** extending right
   - Draw **arrow point** at end
7. **Blend edges:**
   - Use **Eraser Tool** (E key) with soft brush
   - Erase where arrow meets H to blend seamlessly

**Method C: Copy from Image 1 (Fastest)**

1. **Open Image 1** in new Photopea tab
2. **Select Lasso Tool** (L key)
3. **Draw around the arrow** (right side of H)
4. **Edit → Copy** (Ctrl+C)
5. **Switch to Image 2 tab**
6. **Edit → Paste** (Ctrl+V)
7. **Move arrow** to correct position (Move Tool - V key)
8. **Transform** (Ctrl+T) to resize if needed
9. **Blend edges** with soft Eraser if needed

---

### **Phase 3: Fix LOGISTICS GROUP Text Size**

#### Step 6: Remove Old LOGISTICS GROUP Text
1. **Select Healing Brush Tool** (J key)
2. **Hold Alt**, click on **white van area** below PRUSH
3. **Paint over "LOGISTICS GROUP"** text to remove it
4. Make sure it's completely gone

#### Step 7: Create New Smaller LOGISTICS GROUP Text
1. **Select Text Tool** (T key)
2. **Click below PRUSH** (where old text was)
3. **Type:** "LOGISTICS GROUP" (all caps)
4. **In toolbar, set:**
   - **Font:** Same as PRUSH (sans-serif, regular weight)
   - **Size:** **40-45% of PRUSH size**
     - If PRUSH is 200px → LOGISTICS GROUP = 80-90px
     - If PRUSH is 250px → LOGISTICS GROUP = 100-110px
   - **Color:** Dark grey **#666666** (or #2D3748)
   - **Style:** Regular (not bold)
   - **Letter Spacing:** Slightly tighter (-10 to -20)

5. **Position:**
   - **Tight spacing** below PRUSH (10-15px gap)
   - **Center aligned** with PRUSH
   - Use **Move Tool** (V key) to fine-tune

6. **Check proportions:**
   - LOGISTICS GROUP should look **significantly smaller** than PRUSH
   - Should create **visual hierarchy**

---

### **Phase 4: Add Curved Stripe (From Image 2)**

#### Step 8: Check Existing Stripe
- Image 2 already has the curved stripe - **keep it!**
- If it's not visible or needs fixing, continue to Step 9

#### Step 9: Create/Enhance Curved Stripe
1. **Create new layer** "Curved Stripe"
2. **Select Pen Tool** (P key)
3. **Draw curved path:**
   - Start at **front wheel arch**
   - Curve **upward** toward rear
   - End near **rear wheel arch**
   - Follow the curve from Image 2

4. **Make selection:**
   - **Right-click path → Stroke Path**
   - Choose **Brush** (not pencil)
   - **Width:** 8-12 pixels (adjust to match Image 2)
   - Click **OK**

5. **Or use Shape Tool:**
   - **Select Shape Tool** (U key)
   - Choose **Line** or **Custom Shape**
   - Draw curved stripe
   - **Transform** (Ctrl+T) to adjust curve

6. **Set color:**
   - **#EA580C** (burnt orange)
   - Match the orange from PRUSH logo

7. **Position:**
   - **Lower side of van**
   - Just above wheel arch
   - Curved upward toward rear

---

### **Phase 5: Add Slogan (From Image 2)**

#### Step 10: Check Existing Slogan
- Image 2 has the slogan - **keep it!**
- If it needs fixing or repositioning, continue to Step 11

#### Step 11: Create/Enhance Slogan
1. **Select Text Tool** (T key)
2. **Click below LOGISTICS GROUP** (or on bottom of side panel)
3. **Type:** "We put the rush in Prush"
4. **In toolbar, set:**
   - **Font:** Sans-serif, **Italic style**
   - **Size:** 30-35% of PRUSH size
   - **Color:** Start with dark grey (#666666)

5. **Color Individual Words:**
   - **Select word "rush"** → Change to orange (#EA580C)
   - **Select word "Prush"** → Change to orange (#EA580C)
   - **Keep "We put the" and "in"** as dark grey (#666666)

6. **Position:**
   - **Bottom of side body panel** (not on door)
   - **Center aligned** with logo above
   - **Smaller and subtle** than main logo

7. **Add small arrow above slogan** (optional, from Image 2):
   - **Create new layer**
   - **Brush Tool** (B key)
   - Draw small arrow pointing right
   - Color: Orange (#EA580C)
   - Position above slogan

---

### **Phase 6: Apply to All Three Vans**

#### Step 12: Copy Branding to Other Vans
1. **Select all logo layers:**
   - Hold **Shift**, click each layer:
     - PRUSH Logo
     - LOGISTICS GROUP Text
     - Arrow Fix
     - Curved Stripe
     - Slogan

2. **Group layers:**
   - **Right-click → Group from Layers**
   - Name it "Branding"

3. **Duplicate group:**
   - **Right-click group → Duplicate Group**
   - Name it "Branding Van 2"

4. **Move to second van:**
   - **Select Move Tool** (V key)
   - **Click on duplicated group**
   - **Move to second van's side panel**
   - **Transform** (Ctrl+T) if size needs adjustment

5. **Repeat for third van:**
   - Duplicate group again
   - Move to third van
   - Adjust position/size as needed

6. **Ensure consistency:**
   - All three vans should have **identical branding**
   - Same size, same position, same colors
   - Use **guides** (View → New Guide) to align

---

### **Phase 7: Final Polish**

#### Step 13: Check Everything
1. **Zoom out** (Ctrl + Minus) to see full image
2. **Check each van:**
   - ✅ Arrow blends seamlessly into H (Image 1 style)
   - ✅ LOGISTICS GROUP is smaller (40-45% of PRUSH)
   - ✅ Curved stripe is visible on all vans
   - ✅ Slogan is correctly spelled and colored
   - ✅ All branding is consistent across all three vans

#### Step 14: Fine-Tune Colors
1. **Select each text layer**
2. **Double-check colors:**
   - PRUSH: Orange (#EA580C)
   - Arrow: Orange (#EA580C)
   - LOGISTICS GROUP: Dark grey (#666666)
   - Slogan "rush" and "Prush": Orange (#EA580C)
   - Slogan other words: Dark grey (#666666)
   - Stripe: Orange (#EA580C)

#### Step 15: Adjust Spacing & Alignment
1. **Use guides** to align elements:
   - **View → New Guide → Vertical** (for center alignment)
   - **View → New Guide → Horizontal** (for logo height)

2. **Check spacing:**
   - PRUSH to LOGISTICS GROUP: 10-15px
   - LOGISTICS GROUP to Slogan: 15-20px
   - Logo to stripe: Appropriate distance

#### Step 16: Export Final Image
1. **File → Export As → PNG** (or JPG)
2. **Quality:** 100% (for printing)
3. **Resolution:** High (300 DPI if available)
4. **Save** with name like "Prush_Trucks_Final.png"

3. **Use Guides:** Align elements perfectly with guides
4. **Zoom In:** Work at 100-200% zoom for precise edits

## 🆘 TROUBLESHOOTING

### Arrow Doesn't Blend:
- Use **softer Eraser** (0% hardness)
- **Lower opacity** on arrow layer (90-95%)
- **Blur edges** slightly (Filter → Blur → Gaussian Blur → 1-2px)

### LOGISTICS GROUP Too Big/Small:
- **Select text layer**
- **Transform** (Ctrl+T)
- **Hold Shift** (maintains proportions)
- **Resize** until it's 40-45% of PRUSH height

### Colors Don't Match:
- Use **Eyedropper Tool** (I key)
- Click on existing orange text to sample exact color
- Apply to new elements

### Can't See All Three Vans:
- **Image → Canvas Size** to make canvas larger
- Or **Transform** (Ctrl+T) to scale down vans slightly
