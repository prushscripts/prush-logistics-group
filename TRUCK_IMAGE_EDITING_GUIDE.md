# Professional Truck Image Editing Guide - Photopea

## Purpose
Edit your truck images to show **exactly how the branding should look** on the actual vehicles. These edited images will serve as **reference designs** for your decal manufacturer.

---

## Step 1: Open and Prepare Your Truck Image

### 1.1 Open Image in Photopea
1. Go to **photopea.com**
2. **File → Open** (or drag and drop your truck image)
3. Your image should be the truck photo (e.g., `truck3choice.png`)

### 1.2 Check Image Quality
- Make sure image is **high resolution** (at least 2000px wide)
- If image is low quality, you may need to request a higher-res version
- Zoom in to check if truck details are clear

---

## Step 2: Create Your Logo Elements

### 2.1 Create "PRUSH" Text Layer

1. Select **Text Tool** (press **T** key)
2. Click on the truck's side panel where logo should go
3. Type: **"PRUSH"** (all caps)
4. In the top toolbar, set:
   - **Font:** Bold Sans-Serif (Arial Black, Helvetica Bold, or similar)
   - **Size:** Adjust to match truck scale (start with 200-300px, adjust as needed)
   - **Color:** Click color swatch → Set to orange: **#EA580C** or RGB: **234, 88, 12**
   - **Style:** Bold
   - **Alignment:** Center (if needed)

5. Position the text:
   - **Upper-middle section** of side panel (above center line)
   - **Horizontally centered** on the side panel
   - Use **Move Tool** (V key) to position precisely

### 2.2 Add Arrow to the H

**Option A: Using Pen Tool (Most Professional)**
1. Create new layer (Ctrl+Shift+N)
2. Select **Pen Tool** (P key)
3. Draw arrow extending from right side of H:
   - Click at the right edge of H
   - Click further right to create arrow point
   - Click back to create arrow base
   - Close path to complete arrow shape
4. Right-click path → **Fill Path** → Choose orange color (#EA580C)
5. Make arrow **seamlessly blend** into the H letter

**Option B: Using Shape Tool (Easier)**
1. Create new layer
2. Select **Shape Tool** (U key)
3. Choose arrow shape from options
4. Draw arrow extending from H
5. Fill with orange color
6. Use **Transform** (Ctrl+T) to adjust size and angle

**Option C: Using Brush Tool (Quick)**
1. Create new layer
2. Select **Brush Tool** (B key)
3. Set brush size to match H stroke width
4. Draw arrow extending from H
5. Use **Eraser Tool** (E key) to refine edges

### 2.3 Create "LOGISTICS GROUP" Text Layer

1. Select **Text Tool** (T key)
2. Click **directly below** the PRUSH text
3. Type: **"LOGISTICS GROUP"** (all caps)
4. In toolbar, set:
   - **Font:** Regular Sans-Serif (Arial, Helvetica - same family as PRUSH)
   - **Size:** **40-45% of PRUSH size** (if PRUSH is 250px, make this 100-110px)
   - **Color:** Grey - **#666666** or RGB: **102, 102, 102**
   - **Style:** Regular (not bold)
   - **Letter Spacing:** Slightly tighter (adjust in Character panel)

5. Position:
   - **Tight spacing** below PRUSH (about 10-15px gap)
   - **Center aligned** with PRUSH
   - Use **Move Tool** (V key) to fine-tune

### 2.4 Create Tagline "We put the rush in Prush"

1. Select **Text Tool** (T key)
2. Click below LOGISTICS GROUP
3. Type: **"We put the rush in Prush"**
4. In toolbar, set:
   - **Font:** Regular Sans-Serif, **Italic style**
   - **Size:** **30-35% of PRUSH size** (if PRUSH is 250px, make this 75-85px)
   - **Color:** Start with grey (#666666)

5. **Color Individual Words:**
   - Select the word **"rush"** → Change color to orange (#EA580C)
   - Keep "We put the" and "in Prush" as grey (#666666)
   - Make "rush" **bold** or slightly larger for emphasis

6. Position:
   - **Below LOGISTICS GROUP** with about 10-15px gap
   - **Center aligned** with everything above
   - **Smaller and more subtle** than main logo

### 2.5 Add Orange Stripe (Optional)

1. Create new layer
2. Select **Pen Tool** (P key) or **Shape Tool** (U key)
3. Draw curved stripe along bottom of side panel
4. Fill with orange (#EA580C)
5. Position at bottom third of side panel
6. Make it **thin** (about 2-3% of panel height)

## Step 3: Professional Placement Guidelines

### 3.1 Logo Position on Side Panel

**Vertical Placement:**
- **Upper-middle section** (above center line)
- **Top third to upper-middle** of side panel
- **NOT too high** (leave space from top edge)
- **NOT too low** (should be visible and prominent)

**Horizontal Placement:**
- **Centered** on side panel
- **Equal spacing** from left and right edges
- Use **guides** (View → Show → Rulers, then drag from rulers) to center

### 3.2 Logo Size Relative to Truck

**PRUSH should be:**
- **30-35% of side panel height** (if panel is 60 inches tall, logo should be 18-21 inches)
- **Large enough to be readable** from 50+ feet away
- **Proportional** to the truck size

**Visual Check:**
- Zoom out to see full truck
- Logo should look **prominent but not overwhelming**
- Should feel **balanced** on the side panel

### 3.3 Spacing Between Elements

- **PRUSH to LOGISTICS GROUP:** Tight (10-15px or 0.5-0.75 inches)
- **LOGISTICS GROUP to Tagline:** Medium (10-15px)
- **Overall grouping:** Should feel like **one cohesive unit**

---

## Step 4: Color Accuracy

### 4.1 Orange Color
- Use: **#EA580C** (RGB: 234, 88, 12)
- This is your brand orange
- Apply to: PRUSH text, arrow, "rush" in tagline, stripe

### 4.2 Grey Colors
- **LOGISTICS GROUP:** **#666666** (medium grey, 60% black)
- **Tagline text:** **#808080** (lighter grey, 50% black)
- These provide good contrast on white trucks

### 4.3 Color Picker in Photopea
1. Click color swatch in toolbar
2. Enter hex code: **#EA580C** for orange
3. Or use RGB values: **R:234 G:88 B:12**

---

## Step 5: Typography Refinement

### 5.1 Font Selection
- **PRUSH:** Bold, Sans-Serif (Arial Black, Helvetica Bold, Montserrat Bold)
- **LOGISTICS GROUP:** Regular, Sans-Serif (same family as PRUSH)
- **Tagline:** Regular, Italic, Sans-Serif (lighter weight)

### 5.2 Letter Spacing (Tracking)
- **PRUSH:** Slightly tighter (-10 to -20 tracking)
- **LOGISTICS GROUP:** Normal or slightly tighter
- **Tagline:** Normal

### 5.3 Line Height
- Keep lines **tight** but readable
- LOGISTICS GROUP should feel connected to PRUSH

---

## Step 6: Professional Polish

### 6.1 Alignment
1. Show **Rulers:** View → Show → Rulers (Ctrl+R)
2. Drag **guides** from rulers to center elements
3. Use **Align Tools** in toolbar to center horizontally
4. Make sure all text layers are **perfectly aligned**

### 6.2 Perspective and Warp (If Needed)
- If truck is at an angle, you may need to **warp text** to match perspective
- Select text layer → **Edit → Transform → Warp**
- Adjust to match truck's angle
- Be careful not to distort too much

### 6.3 Shadow/Depth (Optional)
- Add subtle **drop shadow** to text for depth
- Right-click text layer → **Blending Options** → **Drop Shadow**
- Keep it **subtle** (opacity: 20-30%, distance: 2-3px)
- This helps text "pop" off the white truck

---

## Step 7: Layer Organization

### 7.1 Organize Your Layers
Name your layers clearly:
- **"PRUSH Text"**
- **"Arrow"**
- **"LOGISTICS GROUP Text"**
- **"Tagline Text"**
- **"Orange Stripe"** (if used)
- **"Background"** (original truck image)

### 7.2 Group Layers
1. Select all logo layers (hold Ctrl, click each)
2. Right-click → **Group Layers** (or Ctrl+G)
3. Name group: **"Logo Elements"**
4. This makes editing easier

---

## Step 8: Save Your Work

### 8.1 Save Editable Version
1. **File → Save As PSD**
2. This keeps all layers editable
3. Name it: `truck-branded-editable.psd`

### 8.2 Export Reference Image
1. **File → Export As → PNG** (or JPG)
2. **Quality:** Maximum
3. This is your **reference image** for decal designer
4. Name it: `truck-branded-reference.png`

### 8.3 Export Multiple Views
- **Full truck view** (zoomed out)
- **Close-up of logo** (zoomed in)
- **Side panel detail** (cropped to just logo area)

---

## Step 9: Create Reference Package for Decal Designer

### 9.1 What to Provide
1. **Edited truck images** (showing how it should look)
2. **Logo file** (your `plgbannerlogo.png`)
3. **Color specifications:**
   - Orange: #EA580C (RGB: 234, 88, 12)
   - Grey: #666666 (RGB: 102, 102, 102)
4. **Typography specifications:**
   - Font families used
   - Sizes relative to each other
5. **Placement notes:**
   - Where on side panel (upper-middle, centered)
   - Size relative to panel (30-35% of height)

### 9.2 Measurements to Include
- **Truck side panel dimensions:**
  - Width: ___ inches
  - Height: ___ inches
- **Logo size on truck:**
  - PRUSH height: ___ inches
  - LOGISTICS GROUP height: ___ inches
  - Overall logo height: ___ inches

## Quick Photopea Workflow Summary

1. **Open truck image** → File → Open
2. **Create PRUSH text** → T key, type "PRUSH", set to orange, bold, large size
3. **Add arrow to H** → Pen/Shape tool, draw arrow, fill orange
4. **Create LOGISTICS GROUP** → T key, type text, set to grey, 40-45% of PRUSH size
5. **Create tagline** → T key, type text, italic, grey with orange "rush"
6. **Position everything** → Move tool (V), center on side panel, upper-middle
7. **Refine spacing** → Tight between elements, balanced overall
8. **Add guides** → View → Show → Rulers, drag guides to center
9. **Save PSD** → Keep editable version
10. **Export PNG** → Reference image for decal designer

---

## Pro Tips

1. **Work at 100% zoom** when positioning text for accuracy
2. **Zoom out frequently** to see overall truck appearance
3. **Use guides** for perfect alignment
4. **Group related layers** for easier management
5. **Save frequently** (Ctrl+S)
6. **Keep original truck image** as background layer
7. **Test different sizes** - what looks good on screen might need adjustment
8. **Get feedback** - show edited image to others before finalizing

---

## Common Mistakes to Avoid

- ❌ Logo too small (won't be visible from distance)
- ❌ Logo too large (overwhelming)
- ❌ Poor spacing (elements feel disconnected)
- ❌ Wrong colors (doesn't match brand)
- ❌ Off-center placement (looks unprofessional)
- ❌ Text too low on panel (gets hidden by cargo)
- ❌ Inconsistent typography (mixing too many fonts)
- ❌ Arrow not properly integrated into H
